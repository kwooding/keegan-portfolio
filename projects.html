Real-Time Chat Server

Distributed Backend System

Java 21 · Spring Boot 4 · PostgreSQL · Redis · Docker · Kubernetes · Nginx · AWS (LocalStack)

A horizontally-scalable, real-time chat backend built to production-grade architecture standards. Started as a single-process app and evolved into a stateless, authenticated, distributed system.

  • Real-time WebSocket messaging via STOMP with a pub/sub broker model
  • Stateless JWT authentication with BCrypt password hashing and role-based access control
  • PostgreSQL persistence with JPA/Hibernate and Flyway schema migrations
  • Redis pub/sub for cross-instance message relay, presence tracking, and rate limiting
  • Multi-stage Docker builds orchestrated with Docker Compose (dual app instances + Nginx load balancer)
  • Kubernetes deployment with Deployments, Services, ConfigMaps, Secrets, health probes, self-healing, and Horizontal Pod Autoscaling
  • AWS cloud fundamentals (IAM, ECR, ECS, Lambda, CloudWatch) practiced locally via LocalStack

Skills demonstrated: distributed-systems design, stateless service architecture, secure authentication patterns, containerization, container orchestration, and cloud infrastructure literacy.
